Overview

BoMGerman is a Bomberman-inspired game built in C++ with SFML. Two players share a keyboard, move through an arena of crates and place timed bombs while trying to avoid the explosions.

I painted the characters in watercolour and converted the artwork into directional sprites for the game. Each character has separate images for moving forwards, backwards, left and right.

My character illustrations

Each character has four views: front, left, back and right. The game switches between these sprites as the player changes direction.

Gameplay

Crates shape the paths through the arena. Bombs detonate after a short delay, sending out particles that can hit a player or trigger another bomb. Positioning and leaving yourself an escape route matter.

Player one

W A S D to move
Left Ctrl to place a bomb

Player two

Arrow keys to move
Right Ctrl to place a bomb

How it works

The code separates the main game systems into classes. Game runs the update and drawing loop, sets up the arena and checks collisions. Hero handles each player’s movement, direction and bomb placement.

Bomb counts down for two seconds, plays a sound and creates a ParticleSystem for the explosion. These particles affect gameplay: crates block them, players can be hit, and nearby bombs can trigger chain reactions.

SFML provides graphics, keyboard input, timers and audio. The implementation brings together object-oriented C++, game-loop logic, collision handling and original visual assets.
