Using Constraint Logic Programming in Third-Generation Programming Languages

Overview

For my graduation thesis at Mathematical Grammar School in Belgrade, I explored how constraint logic programming can be used in popular programming languages such as C#, C++, Python and Java to solve puzzles and scheduling problems.

I completed the project in May 2022 under the supervision of Prof. Filip Hadžić.

The approach

I approached each problem by identifying the decisions to make, the possible values and the rules a solution must satisfy. Once those rules are encoded, a solver searches for a valid combination of values.

To understand that search, I studied how constraint propagation rules out impossible values and how backtracking revisits earlier choices when a solution cannot be completed. I also explored local search and the AC-3 consistency algorithm.

Puzzles & scheduling

Mathematical puzzles

I began with Prolog and CLPFD, modelling a letter-to-digit arithmetic puzzle. I then used C# and Decider to model cryptarithmetic, Sudoku, Einstein’s riddle and the magic hexagon.

These puzzles combine different kinds of constraints, including arithmetic equations, unique values and logical relationships.

A meeting scheduler

I applied the same modelling approach to an object-oriented C# prototype that finds a meeting time and room. It accounts for attendees’ working hours, absences, existing meetings and room availability, and reports when no suitable slot exists within the day.

Across languages

I then implemented the same constraint model using Naxos Solver in C++, python-constraint in Python and Choco Solver in Java. Keeping the problem fixed let me compare how each library defines variables, expresses rules and requests solutions.

These implementations use finite integer domains: each variable has a bounded set of possible values.

Conclusions

Constraint models can be expressed in general-purpose languages through solver libraries. The implementations use finite integer domains, so the choice of library depends on the variable types and constraints a problem requires. Search performance is another consideration when moving to larger problems.
